# 自定义回复插件（astrbot_plugin_reply）

AstrBot 的关键词回复插件。在插件自带的 WebUI 页面里管理回复、作用域、冷却和统计，不启动额外服务，也不调用大模型。

## 功能

- 四种匹配方式：精确、包含、前缀、正则，一条回复可绑定多个关键词。
- 四种回复类型：固定文本、随机文本、多段文本、多媒体消息链（图片、视频、语音、文件、At）。
- 每条回复可单独设置黑白名单、冷却、每日上限和允许时间段，并可用文件夹分类。
- 统计和冷却写入插件数据目录，重载或重启后保留。

## 安装与打开

在 AstrBot 插件市场安装 `https://github.com/yiyinfaith/astrbot_plugin_reply`，要求 AstrBot `>=4.18,<5`。

安装后进入「插件」→「自定义回复插件」详情页，打开可视化视图「自定义回复插件」。

## 回复参数

| 参数 | 说明 | 限制与默认 |
| --- | --- | --- |
| 回复名称 | 列表和统计中显示的名称 | 必填，最长 120 字符 |
| 文件夹 | 所属分类 | 默认未分类 |
| 关键词 | 每行一个 | 至少 1 个，最多 100 个，单个最长 2000 字符 |
| 匹配方式 | 精确 / 包含 / 前缀 / 正则 | 默认精确，正则保存时校验 |
| 大小写敏感 | 关闭时按 Unicode `casefold()` 比较 | 默认关闭 |
| 回复类型 | 见下方「回复类型」 | 默认固定文本 |
| 优先级 | 数值越大越优先 | `-100000` 到 `100000`，默认 `0` |
| 作用域 | 黑名单排除、白名单仅允许所列群号和用户 ID | 默认黑名单，白名单留空时不会触发 |
| 回复 / 用户 / 群聊冷却 | 单位为秒，三项独立 | `0` 不限制，最长 1 年 |
| 每日触发上限 | 按服务器当天计数 | `0` 不限制 |
| 允许时间段 | `HH:MM`，开始和结束必须同时填写，可跨午夜 | 留空表示全天 |

### 回复类型

| 类型 | 填写方式 | 发送效果 |
| --- | --- | --- |
| 固定文本 | 回复内容 | 原样发送 |
| 随机文本 | 每行一条，最多 100 条 | 随机发送其中一条 |
| 多段文本 | 每行一段，最多 100 段 | 每段单独发送一条消息，按顺序发出，空行跳过 |
| 多媒体消息链 | 按顺序添加组件，最多 100 个 | 由平台适配器发送 |

多媒体组件的填写：图片、视频、语音、文件填平台可访问的 URL 或 AstrBot 进程可访问的本地路径；At 填目标用户 ID，填 `{sender}` 可 At 发送者。文件的显示名可选，留空时使用真实文件名。

### 动态变量

回复内容和多媒体组件都可使用，未知占位符会原样保留。

| 变量 | 含义 |
| --- | --- |
| `{sender}` | 发送者 ID |
| `{nickname}` | 发送者昵称 |
| `{group_id}` | 群号，私聊为空 |
| `{group_name}` | 群名称，平台不提供时为空 |
| `{time}` | 当前时间，`HH:MM:SS` |
| `{date}` | 当前日期，`YYYY-MM-DD` |
| `{random}` | `0` 到 `999999` 的随机数 |

## 匹配顺序

1. 检查全局作用域，以及回复自身的启用状态、作用域和时间段。
2. 排除正在冷却或已达每日上限的回复。
3. 按优先级从高到低，只发送排在最前的一条。同优先级依次按精确、前缀、包含、正则，再按关键词长度和回复 ID 排序。

精确、包含、前缀匹配前会规范化消息（NFKC、折叠连续空白）；正则直接匹配原始消息。

编辑页底部的「回复测试」只预览匹配结果和变量，不检查冷却和每日上限，不写统计，也不向平台发消息。

## 全局设置

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 仅响应 @机器人或唤醒命令 | 关闭后所有普通消息都会参与匹配 | 开启 |
| 全局作用域 | 对所有回复生效的黑白名单 | 黑名单，留空 |
| WebUI 管理员账号 | 限制可管理回复的面板账号，填写时必须包含当前账号 | 留空表示所有已登录账号 |
| `normalization` | `unicode_nfkc`、`collapse_whitespace` 两个开关，只能通过导入 JSON 的 `settings` 修改 | 全部开启 |

## 导入与导出

导出文件包含回复、文件夹和全局设置。导入会校验全部内容，通过后替换当前回复和文件夹，覆盖文件中的全局设置（WebUI 管理员列表除外），并清空冷却和每日计数。建议批量修改前先导出备份。

## 数据存储

数据保存在 `data/plugin_data/astrbot_plugin_reply/reply_rules.json`，采用原子写入。如果文件损坏无法解析，插件会把它改名为 `reply_rules.json.corrupt-<时间戳>` 保留，再以空数据启动。
